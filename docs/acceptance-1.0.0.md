# 1.0.0 验收记录

本次修改从 master 创建 codex/release-1.0.0，整合 feature/desktop-gui 的窗口和托盘实现。

## 自动化验证

- Python：38 项通过，覆盖命名限制、配置原子写入、同步游标、失败任务、缓存复用、取消、启动恢复、Cookie 隔离、通知和发布流程。
- 前端：lint、构建和 7 项 Vitest 测试通过；8 项 Playwright 流程在桌面和移动视口通过。
- 浏览器流程使用构建后的前端，验证登录、深色主题、长标题、日志、键盘调整列宽、重试、页面刷新和设置保存。
- npm audit 未发现依赖漏洞。
- 后端和前端 Docker 镜像构建通过；后端容器健康检查、目录挂载下的配置保存通过。
- Ubuntu 交叉构建的 Windows ZIP 通过文件清单、版本和 SHA-256 校验。

## Windows 11 验证

本机 WebView2 窗口启动、登录、隐藏与显示、托盘初始化、任务页和设置页完整刷新、正常退出通过。
测试使用独立的中文数据路径。桌面自动验收命令为：

```powershell
EFDRR.exe --data-root C:\临时验收目录 --smoke-test C:\临时验收目录\smoke.json
```

该命令使用测试目录的配置，生成不含凭据的 JSON 报告，完成后退出。真实配置不应作为自动验收目录。

## 发布约束

Gitea 在测试与 Windows 包构建通过后，才执行 master 的版本发布。只有 VERSION 发生变化才自动发布；可手动重跑失败流程。
已有正式版本不会被覆盖，同一版本指向不同提交时失败。Release 先作为草稿创建，ZIP、校验文件和更新说明全部上传成功后公开。
最终的 Gitea 流程、PR、标签和附件校验结果以对应流水线和 Release 为准。
