EFDRR Windows 便携版

解压整个 ZIP 包后，双击 EFDRR.exe。
支持 Windows 10/11 x64，需要 Microsoft Edge WebView2 Runtime。
无需安装 Python 或 Node.js。

首次启动会显示初始登录信息，也可以打开程序旁的 config.yaml 查看或修改。
配置、数据库、日志和默认下载目录均保存在程序旁边。
请解压到有写入权限的目录。

关闭窗口可选择退出或进入系统托盘；进入托盘后下载继续。
通过托盘菜单可显示窗口、打开下载目录、打开配置文件和退出程序。

升级前退出程序。保留 config.yaml、data 和 downloads，替换程序文件。
不要直接覆盖正在运行的程序，也不要删除 data 中的数据库与断点文件。

WebView2 下载：https://developer.microsoft.com/microsoft-edge/webview2/
